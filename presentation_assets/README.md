# M.A.V.I.S. — Presentation & Project Expo Assets

This directory contains the presentation slide decks, ISO A3 exhibition poster, architectural diagrams, and institutional assets used for the M.A.V.I.S. (Multi-Modal Animal Vitality Intelligence System) project presentation and expo defense at RNS Institute of Technology (Department of Computer Science & Engineering, VTU).

---

## 1. Project Expo Poster (A3 ISO Landscape)

* **`a3_expo_poster.html`**: Production-grade, high-density HTML5/CSS3 print template formatted strictly to ISO A3 landscape (`420mm × 297mm`). Includes three academic columns covering Edge Sensing DSP, Algorithmic Decision Architecture, and Clinical Digital Twin Evaluation.
* **`MAVIS_A3_Project_Expo_Poster.pdf`**: Pre-rendered, 300 DPI vector-sharp PDF ready for direct large-format printing.

---

## 2. Interactive Presentation Slides & Diagrams

* **`presentation_slides_compact.html`**: Presentation deck covering baseline anomaly mathematics, risk engine formulation, and system architecture.
* **`slide_architecture_ppt.html`**: Dedicated architectural data-flow slide formatted for 16:9 presentation projection.
* **`mavis_methodology_diagrams.html`**: Step-by-step engineering methodology flowcharts and state-machine transitions.
* **`presentation_slide_16x9.html`**: Responsive 16:9 widescreen presentation layout.
* **`presentation_diagram.html`**: Standalone interactive SVG/Mermaid component architecture diagram.
